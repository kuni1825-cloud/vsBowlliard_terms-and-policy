# Vs.Bowlliard（対決！ボーラード）

## 孤独なボーラードに、ライバルを。

いつものビリヤード練習に、対戦の楽しさを。

Vs.Bowlliardは、実際のビリヤード台で行うボーラードのスコアを記録しながら、29人のキャラクターとの対戦を楽しめるiPhoneアプリです。

入れた球の数やミスの原因をタップで入力。練習の成果を残しながら、自分の得意と苦手を振り返れます。

## 29人のライバルと対戦

個性豊かなキャラクターたちが、あなたの挑戦を待っています。

実際にプレイしたスコアを入力すると、フレームごとに対戦が進みます。相手を追いかける緊張感や、勝ち進む喜びが、ひとりの練習に新しい目標を生み出します。

※対戦相手はアプリ内のキャラクターです。ほかの利用者とのオンライン対戦ではありません。

## 練習モードは、サックサク入力。

対戦をせず、自分のペースで記録できる練習モードも用意しています。

- 入れた球の数をタップで入力
- スコアを自動計算
- ミスの原因も一緒に記録
- 大きなフレーム表示で、進み具合を確認

練習の合間に、手早く記録を残せます。

## え？これが、苦手だったの？

感覚だけでは気づきにくいミスの傾向を、グラフで確認できます。

ロング、引きミス、撞点など、記録したミスの原因を振り返り、次の練習で意識することを見つけましょう。

## 上達を、くまなく記録。

平均スコアやシュート率、直近の成績、通算成績を確認できます。

プレイを重ね、レベルが上がると、確認できる統計が増えていきます。日々の積み重ねを、自分の成長として振り返れます。

## こんな方におすすめ

- ボーラードのスコアを手軽に記録したい方
- ひとりでの練習に目標がほしい方
- ミスの傾向を知り、練習に役立てたい方
- 成績の変化を見ながら、長く練習を続けたい方

## 使い方

1. 練習モード、または対戦モードを選びます。
2. 実際のビリヤード台でボーラードをプレイします。
3. 入れた球の数と、必要に応じてミスの原因を入力します。
4. 終了後にスコアや統計を振り返ります。

本アプリは、実際のプレイ結果を入力する記録アプリです。画面上で球を撞くゲームではありません。
